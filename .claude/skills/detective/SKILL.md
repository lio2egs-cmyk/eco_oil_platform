# פרוטוקול הבלשית

תפקיד: להגיע ללימור עם תשובה מאומתת, לא עם שאלה. חוק אימות-קודם (ספר החוקים 4) הוא הבסיס. מקרה אחד בכל פעם; תשובה = צעדי פעולה בלבד (2-4 שורות: איזו שורה, אילו ערכים, שורת "למה"); הראיות המלאות רק אם תבקש. יואב מכריע רק מול קובץ.

## לקרוא לפני פעולה
- זיכרון `project_ecodepot_detective_protocol.md` — הפרוטוקול המלא, מלכודות, דוגמאות, לקחי 14/09.
- ספר החוקים ה + ה2: 25-28 (ראיות), 41-47ג (אימות כפול, וריאנטים, מספרנו, שתיקת מקור, ביקורת-נגד, מסמך מתוארך, גיבויים, כיוון הטופס, המייל האחרון, רשימת המובילים).

## סדר החקירה (מהפשוט למורכב, לא מדלגים)
1. **המסד קודם** (`מחירון חדש.xlsx` ▸ מסד חומרים): מצב נוכחי, לא מפת פערים ישנה. חיפוש מדויק + ללא רווחים + ללא NBSP/U+200F + בנרדפים.
2. **השורה החיה** (openpyxl read-only): מה הוקלד, האם מחיר/או"ם זרמו, האם השטיפה חויבה; חשוד ראשי = אי-התאמת שם (רווח, סוגריים, כתיב). איתור לפי מספר מכל, לעולם לא לפי מספר שורה ישן.
3. **אימות כפול לכל טענת קיום/היעדר:** סריקה שנייה בלתי-תלויה במפתח אחר (ספרות בלבד, מספר ביקור, וריאנט עם רווח, 6 ספרות בלי ספרת ביקורת, תאומי-הקלדה, ספרת ביקורת ISO-6346).
4. **תיקיות ותעודות:** `לקוחות\{לקוח}\{שנה}\{חודש}\שטיפה\{טנק}` בשני העצים; PDF תעודה = מקור סמכותי (נושא מספר שורה, תאריכים, חומר). שמות קובצי תמונות = חותמות אמת.
5. **מיילים לפי מספר מכל** (אינדקס `C:\for_eco-depot\decode_2026-07-03\emails_index.json`; X-GM-RAW על All Mail לתוכן צרופות, מילים פשוטות בלבד): טפסי בקשה (STORAGE/CLEANING REQUEST = ראיית כניסה; RELEASE REQUEST = ראיית יציאה), MSDS, הצהרות לקוח, תוכניות העמסה (הבלוק של המכל עצמו). מובילים: המייל האחרון לפני השחרור קובע, לפי חותמת שעה מלאה. שמות קנוניים מ-`CARRIER_OPTIONS`.
6. **אינטרנט:** SDS רשמי של היצרן → עותק ל-`C:\for_eco-depot\MSDS_<חומר>\`. 9003 = ADN בלבד (לא רלוונטי).
7. **משפחה וביקורת-נגד:** מכל אח שאצלו זה כן קרה; שתיקת מקור אינה הוכחה (לכל מקור שטח מת).
8. **גיבויי C:** ו-הזיכרון (בקשות מחיקה של יואב) לפני שחזור/יצירת שורה.

## כללי ברזל
- הראיה המכריעה = מסמך מתוארך שנשלח ללקוח. תמונות שלטים חסרות ערך.
- שגיאת הקלדה → תיקון השורה (לתור); צורת כתיב חוקית → נרדף במסד. הורדת סיכון (→0) = יואב חובה, מול קובץ.
- אין מיילים ללקוחות על ביקורים ישנים. תאים ריקים בלבד; "לא ידוע" מוחלף רק באישור לימור; שם קיים שונה → לא נוגעים, מדווחים. מוביל שמכיל "אקו" מפעיל נוסחת הובלה — לבדוק חיוב לפני כתיבה.
- ממצאי סריקת-לילה/הפרשים = צילום מצב; לבדוק מחדש בקובץ החי לפני שמציגים.
- כל טענה מסומנת מאומת / השערה.

## סגירת מקבץ (בסוף הרשימה, לא מקרה-מקרה)
תיקוני שורות בהרצת COM אחת (ecodepot: אימות מכל + ערך-ישן-צפוי, גיבוי, Disable לגשר) → אחרי מילוי תאריכים בשורת צפי לצרוב מספר ביקור סטטי max+1 → לסגור ידית openpyxl לפני COM → "רענן הכל" אחד → בדיקת השפעה על חיוב (סכומים שחויבו לא זזים; שטיפות ישנות שקיבלו מחיר → ליואב) → סריקת תווים בלתי-נראים במסד → עדכון מפת הפערים במקום + דיווח נסגר/נותר.
