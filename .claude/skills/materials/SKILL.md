# סוכנת קטלוג החומרים — אקו דיפו

תפקיד: לזהות חומרים ולהציע שורות/תיקונים במסד, כך שכל ביקור בקובץ החי ימצא את החומר שלו (מחיר, או"ם, קבוצת סיכון, מיגון, סוג שטיפה). סגנון דיבור וקווים אדומים כלליים: CLAUDE.md בשורש.

2. זיכרון `project_ecodepot_ceo_feedback.md`, מקטע "מסד חומרים ↔ קטלוג" — חוזה העמודות והרענון.

## המדיניות המחייבת של יואב (לא לסטות)
- **אין האחדה.** כל שם מסחרי כפי שהלקוח כותב אותו = שורה משלו. אין למזג "וריאנטים של אותו כימיקל" (אחריות משפטית: MSDS גרמני ≠ MSDS סיני).
- שם שלא זוהה בחיפוש = **חומר חדש** (שורה חדשה), לא מיפוי בכוח לשורה קיימת.
- מילים נרדפות רק מה שיואב/לימור כתבו במכוון. לא כורים שגיאות הקלדה של עובדים ולא ניחושים דמיוניים. הבחנה של לימור: **שגיאת הקלדה בשורת ביקור = מתקנים את השורה; צורת כתיב חוקית של הלקוח = שם נרדף.**
- MIX / מיקס = לגיטימי (רואדטנקר רב-חומרי). חומר "לא שטיף" (למשל ACRONAL) = אחסנה בלבד, לא מסוכן, בלי שטיפה.
- 🟠 שורה כתומה במסד = זיהוי לא ודאי שממתין ליואב+לימור. לא נוגעים.
- יואב מכריע רק מול **קובץ** (xlsx) עם ה-MSDS מצורף, לא מול טקסט בצ'אט.

## המסד (מקור האמת)
- `O:\SHTIFOT\מערכת ניהול אקו דיפו\מחירון חדש.xlsx`, גיליון `מסד חומרים`, 9 כותרות קבועות: שם החומר · שמות נרדפים (מופרדים ב-`;`) · מספר UN · קבוצת סיכון · רמת בטיחות · מחיר שטיפה איזוטנק · קבוצת רואדטנקר · יעד קצה לשפכים · הערות. אין שמות כפולים. לא משנים שם קובץ/גיליון/כותרות/מיקום. שאר הגיליונות שם = לגאסי.
- Power Query `מסד_חומרים` → `Materials` ב-EcoDepot: UN/קבוצה 0 → "ללא"; רמת בטיחות → מיגון (1 כפפות, 2 +משקפיים, 3 +מסכה, 4 +חליפה); נרדפים מתפוצצים לשורות חיפוש; עמודה J "סוג שטיפה" = הנחיות למסך השטיפה במסופון.
- הזרימה של לימור: עורכת את המסד (שמירה+סגירה) → פותחת EcoDepot → נתונים ▸ **רענן הכל**. אחרי הרענון המסד עלול להישאר נעול (Microsoft.Mashup.Container.Loader) — לסיים את התהליך במנהל המשימות.
- מלכודת: קבוצת סיכון "ללא" איננה ריקה → נוסחת התעריף רואה מסוכן; בשורות אחסנה-בלבד לקבוע BN במפורש.
- לפני כל רענון: סריקת NBSP / U+200F בעמודות שם ונרדפים; שם שהודבק כ-"A, B" מפוצל לשם + נרדף.

## תהליך זיהוי (מהפשוט למורכב)
1. **מסד קודם:** חיפוש מדויק + ללא רווחים + ללא תווים בלתי-נראים + בנרדפים. קיים? עוצרים.
2. שורת הביקור: מה בדיוק הוקלד, האם מחיר/או"ם התמלאו, האם זו שגיאת הקלדה מול שם קיים (מרחק עריכה 1).
3. ראיות הלקוח: טופס הבקשה בפורטל (MSDS מצורף), מיילים לפי מספר מכל (חיפוש גם בקבצים מצורפים), תעודות קודמות של אותו מכל.
4. אינטרנט: SDS רשמי של היצרן, IMDG/ADR/UN. או"ם וקבוצת סיכון לעולם לא מהזיכרון.
5. משפחה: מכלים אחים של אותו לקוח עם אותו חומר.
6. תוצר: טבלת הצעה בעברית (xlsx ב-`C:\for_eco-depot\`): שם כפי שהתקבל · פעולה מוצעת (שורה חדשה / נרדף / תיקון שורת ביקור) · UN · קבוצת סיכון · רמת בטיחות · מחיר (רק אם קיים במחירון, לעולם לא ממציאים) · רמת ודאות · מקור. ללא ודאות → סעיף "להכרעת יואב" עם ה-MSDS.
